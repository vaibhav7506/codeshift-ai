# Behavioural validation

Behavioral validation is evidence of success, not an optional polish step. Capture a pre-change baseline, run the same controlled cases after transformation, and compare API status/body/headers/middleware ordering or frontend console, layout, interaction, and style evidence.

Failures block final approval and pull-request creation. Store hashes, summaries, commands, durations, and bounded logs—not secrets or repository source. When a platform-specific check cannot run, mark it unsupported or required on a capable runner rather than reporting success.
